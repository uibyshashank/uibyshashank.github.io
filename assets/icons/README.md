# assets/icons/

Place reusable SVG/PNG icon assets here (e.g. favicon, social icons, feature icons).

Current site status:

- `favicon.svg` — site favicon (referenced in index.html `<head>`).
- The two social glyphs in the contact section are styled text. Drop icons into
  this folder and reference them as `assets/icons/<file>` from index.html when
  you need them.
